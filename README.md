# Real-Time AI Voice Assistant
This project is a real-time AI voice assistant system built using open-source tools.

It supports:
- Speech-to-Text (STT)
- Text-to-Speech (TTS)
- Live transcription
- Real-time voice interaction
- Intent recognition
- Cross-platform support (Windows/Linux)
- Hotkey-based activation

Technologies Used
- Python
- Faster Whisper
- RealtimeSTT
- pyttsx3
- PyAudio
- keyboard

Features
- Press F9 to start listening
- Press F10 to stop listening
- Press ESC to exit assistant
- Open/close Chrome
- Open/close YouTube
- Open/close VS Code
- Multilingual architecture
- Future Indic language support

Run Command:
python main.py
